# Jutt Coder – Flutter Profile App

## About Project

This is a Flutter application developed as part of my Flutter Developer Internship – Task 2.

The project demonstrates the development of a professional user profile screen using built-in Flutter widgets.

## Features

- Professional Profile Screen
- Circular Profile Picture using CircleAvatar
- User Name and Professional Designation
- Email Address
- Personal Information Section
- About Me Section
- Skills Section using Flutter Chips
- Edit Profile Button
- Share Profile Button
- Clean and Professional UI
- Scrollable Layout
- Bottom Navigation Bar

## Technologies Used

- Flutter
- Dart
- Android Studio
- Android SDK
- Material Design

## Flutter Widgets Used

- Scaffold
- AppBar
- Column
- Row
- CircleAvatar
- Container
- Card
- Text
- Icon
- ElevatedButton
- SingleChildScrollView
- Chip
- BottomNavigationBar

## Installation Steps

1. Install Flutter SDK.
2. Install Android Studio.
3. Configure Flutter and Dart plugins.
4. Connect an Android device or start an emulator.
5. Clone or download this project.
6. Open the project folder in Android Studio.
7. Run the following commands:

```bash
flutter pub get
flutter run
```

## Project Structure

```text
my_first_app/
├── android/
├── ios/
├── lib/
│   └── main.dart
├── web/
├── windows/
└── pubspec.yaml
```
