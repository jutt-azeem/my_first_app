# Jutt Coder – My First Flutter App

## About Project
This is my first Flutter application developed as part of my Flutter Developer Internship – Task 1.

The application demonstrates basic Flutter development, UI customization, navigation, and user interaction.

## Features
- Customized Home Screen
- App name: Jutt Coder
- Blue and white theme
- Snackbar notification
- About Me screen
- Navigation between screens
- Material Design UI

## Technologies Used
- Flutter
- Dart
- Android Studio
- Android SDK

## Installation Steps

1. Install Flutter SDK.
2. Install Android Studio.
3. Configure Flutter and Dart plugins.
4. Connect an Android device or start an emulator.
5. Clone or download this project.
6. Open the project folder in Android Studio.
7. Run the following commands:

```bash
flutter pub get
flutter run
```
